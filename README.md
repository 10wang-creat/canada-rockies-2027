# canada-rockies-2027

- `index.html` 首頁：三個目的地、關鍵數據、13 天時間軸
- `itinerary.html` 每日行程（含步道總覽）
- `attractions.html` 景點圖鑑（Wikimedia Commons 實景照片）
- `accommodation.html` / `budget.html` / `packing.html` / `shopping.html` / `tips.html`
- `assets/css/main.css` 全站共用樣式

照片以 `Special:FilePath` 直連 Wikimedia Commons，不存在 repo 內。
